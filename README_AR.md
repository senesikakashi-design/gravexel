# GRAVEXEL - DEFY THE GRAVITY
### A NEW DIMENSION OF MOVEMENT

لعبة منصات وألغاز بلغة C#. شخصية صغيرة تجري وحدها، وأنت تقلب الجاذبية بزر واحد. تعمل اللعبة بالكامل دون إنترنت، ولا تستخدم الإنترنت إلا للتحقق من وجود تحديث.

## الجديد في الإصدار 1.1.0
- **الاسم والهوية:** الاسم الجديد GRAVEXEL، مع شعار جديد اسمه Gravity X، وأيقونة جديدة، ومقدمة متحركة عند التشغيل.
- **إصلاح:** زر Space لم يعد يفتح قائمة الإيقاف المؤقت.
- **مراحل جديدة:** عالمان جديدان أصعب، QUANTUM FORGE وOMEGA RIFT، فيهما 24 مرحلة. فصار المجموع 56 مرحلة.
- **شخصيات جديدة:** 4 شخصيات أُضيفت، فصار المجموع 16 شخصية.
- **التحديث من داخل اللعبة:** بضغطة واحدة.
- **نقل التقدم:** تقدّمك في النسخة القديمة GRAVITY SWITCH ينتقل تلقائياً. والمثبّت الجديد يزيل النسخة القديمة بنفسه.

## نظام التحديث
- عند التشغيل تسأل اللعبة GitHub بصمت: هل يوجد إصدار أحدث؟ إذا لم يوجد إنترنت فلا يحدث شيء.
- إذا وُجد إصدار أحدث يظهر زر **UPDATE AVAILABLE** في القائمة الرئيسية. تضغطه فتظهر لك ملاحظات الإصدار، ثم **UPDATE NOW**، فتُنزَّل النسخة الجديدة وتُثبَّت، وتُعاد اللعبة للتشغيل تلقائياً.
- يمكنك أيضاً التحقق يدوياً من **SETTINGS ← CHECK FOR UPDATES**.

## الرفع على GitHub (مرة واحدة)
1. أنشئ مستودعاً جديداً باسم **gravexel** على حسابك `senesikakashi-design`.
2. ارفع محتويات المجلد كاملة إلى المستودع.
3. انشر أول إصدار بهذه الأوامر:
   ```
   git tag v1.1.0
   git push --tags
   ```
   سيبني GitHub ملف الـ EXE والمثبّت تلقائياً، وينشرهما في صفحة Releases.

إذا اخترت اسماً آخر للمستودع، أخبرني لأعدّل الرابط داخل اللعبة.

## نشر تحديث جديد لاحقاً
1. غيّر رقم الإصدار في `Unity/Assets/Gravexel/Scripts/Core/GameApp.cs`، مثلاً `Version = "1.2.0"`.
2. اكتب ما الجديد في الملف `CHANGELOG-latest.md`. سيظهر هذا النص للاعبين داخل اللعبة.
3. نفّذ الأوامر التالية:
   ```
   git commit -am "v1.2.0"
   git tag v1.2.0
   git push
   git push --tags
   ```
بعدها يرى كل من ثبّت اللعبة زر التحديث.

## الهوية البصرية (مجلد Brand)
- **الشعار:** اسم GRAVEXEL نفسه. حرف X فيه مكوّن من سهمين: سهم سماوي نازل من فوق، وسهم وردي صاعد من جوه. فيُقرأ X، ويرمز بنفس الوقت للصعود والنزول، وهي فكرة اللعبة.
- **ألوان الاسم:** "GRAV" بالسماوي، والباقي بالأبيض.
- **أيقونة التطبيق:** السهمان وحدهما على خلفية متدرجة من الكحلي إلى البنفسجي.
- **الملفات:**
  - `out/logo`: الشعار، والشعار مع العبارتين، ونسخ بلون واحد (أبيض وأسود).
  - `out/icons`: كل مقاسات Android وiOS.
  - `out/store`: صورة Google Play الترويجية، وشاشة بدء للموبايل، وغلاف.
- **الخطوط:** Audiowide للعناوين، وRajdhani للواجهة. كلاهما مجاني برخصة OFL.
- **إعادة التوليد:** `python Brand/make_brand.py`. نماذج الهوية الأخرى التي عُرضت موجودة في `out/options` و`out/variants-A`.

## الاختبارات
- أداة الحل الآلية أثبتت أن المراحل الـ56 كلها قابلة للحل مع جمع النجوم الثلاث.
- اختبار لعب آلي أنهى المراحل الـ56 كلها بثلاث نجوم، مع الضغط على Space تماماً كما يضغطها اللاعب.
- شُغّلت اللعبة في نافذة حقيقية للتأكد من أن Space يقلب الجاذبية ولا يفتح الإيقاف.
- يمكنك تشغيل الاختبار بنفسك من قائمة ابدأ: **Self-test**.

## مشروع Unity (للموبايل)
1. افتح مجلد `Unity` في Unity 6.
2. من القائمة العلوية **GRAVEXEL** اختر **1. Setup Project**.
3. ثم **2. Build Windows EXE** لنسخة الكمبيوتر، أو **4. Build Android APK** لنسخة الأندرويد.
